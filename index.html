วิธีเปิดเว็บนี้ให้ออนไลน์ฟรีตลอด 24 ชม. ด้วย GitHub Pages

คุณสามารถนำเว็บนี้ไปเผยแพร่ให้ผู้เล่น Arknights คนอื่นเข้ามาดูไกด์ของคุณได้ง่ายๆ ผ่านโดเมนแบบเดียวกับ is-central.github.io โดยทำตามขั้นตอนดังนี้:

  1. สมัครสมาชิก GitHub: เข้าไปที่ github.com (สมัครฟรีไม่มีค่าใช้จ่าย)
  2. สร้าง Repository ใหม่: กดปุ่ม + มุมขวาบน แล้วเลือก New repository
  3. ตั้งชื่อคลังโค้ด: เช่น arknights-is-guide แล้วกด Create repository
  4. วางไฟล์เว็บ: กดปุ่ม uploading an existing file แล้วลากไฟล์ index.html นี้ขึ้นไป จากนั้นกด Commit changes
  5. เปิดระบบโดเมน: ไปที่เมนู Settings > Pages แล้วเปลี่ยนช่อง Branch เป็น main แล้วกด Save
เพียงเท่านี้ เว็บไซต์ไกด์ของคุณจะออนไลน์ที่ URL: https://[ชื่อบัญชีของคุณ].github.io/arknights-is-guide
